Component Hierarchy — EMS_M1 (Milestone 1)

Source: docs/spec_brief.txt §15.1
==========================================

App                                      (client/src/app/App.jsx)
|  Seeds mock DB on mount (MockApiService.seedIfEmpty).
|  Renders a loading screen until seed completes.
|  Wraps the entire tree in BrowserRouter.
|
+-- AppRoutes                            (client/src/app/routes.jsx)
|   |  Full route table nested under MainLayout.
|   |  LandingRedirect inline component dispatches "/" by role.
|   |
|   +-- MainLayout                       (client/src/components/layout/MainLayout.jsx)
|   |   |  Persistent shell rendered for every route.
|   |   |
|   |   +-- NavigationMenu              (client/src/components/layout/NavigationMenu.jsx)
|   |   |       Role-aware nav bar. Re-reads auth.getCurrentUser() on
|   |   |       every location change (useEffect on pathname).
|   |   |       Three visual states:
|   |   |         Unauthenticated -- Login, Register links
|   |   |         Teacher         -- Dashboard, My Exams, New Exam,
|   |   |                           Submissions, Logout
|   |   |         Student         -- Dashboard, Available Exams,
|   |   |                           Grades, Logout
|   |   |
|   |   +-- <main> / Outlet             Page slot; matched child route renders here.
|   |
|   +-- ProtectedRoute (shared)         (client/src/components/shared/ProtectedRoute.jsx)
|   |       Route guard wrapping all teacher/student page routes.
|   |       No user       -> Navigate to /login
|   |       Wrong role    -> Navigate to own home (/teacher or /student)
|   |       Correct role  -> renders children
|   |
|   +-- LandingRedirect (inline)        Inside routes.jsx, not a separate file.
|           Handles path "/". Dispatches:
|             No user  -> /login
|             Teacher  -> /teacher
|             Student  -> /student
|
+-- Auth Pages
|   |
|   +-- LoginPage                       (client/src/pages/auth/LoginPage.jsx)
|   |       Controlled form: email + password.
|   |       Calls auth.login(). Shows demo credentials hint.
|   |       On success: navigates to "/" (LandingRedirect handles role dispatch).
|   |
|   +-- RegisterPage                    (client/src/pages/auth/RegisterPage.jsx)
|           Controlled form: name, email, password, role select.
|           Roles populated from config.getRoles() (no magic strings in JSX).
|           On success: navigates to "/".
|
+-- Teacher Pages  (all behind ProtectedRoute role="teacher")
|   |
|   +-- TeacherDashboard                (client/src/pages/teacher/TeacherDashboard.jsx)
|   |       Counter cards: Total, Draft, Published, Closed, Submissions (stub 0).
|   |       Quick-links: Create New Exam, View My Exams, Submissions.
|   |       Data: examService.getExamsByTeacher(user.id).
|   |
|   +-- TeacherExamsPage                (client/src/pages/teacher/TeacherExamsPage.jsx)
|   |       Table: title, status badge, duration, question count, actions.
|   |       Per-row actions:
|   |         Edit    -- always shown, links to /teacher/exams/:id/edit
|   |         Publish -- shown if status === Draft
|   |         Close   -- shown if status === Published
|   |         (no actions for Closed)
|   |       Calls examService.publishExam / closeExam; re-fetches list on success.
|   |
|   +-- CreateExamPage                  (client/src/pages/teacher/CreateExamPage.jsx)
|   |   |   Form: title, description, durationMinutes, question list.
|   |   |   Validates: title non-empty, at least 1 question.
|   |   |   On submit: examService.createExam -> navigate /teacher/exams.
|   |   |
|   |   +-- QuestionEditor (local)      Unexported sub-component inside CreateExamPage.
|   |           Per-question form: type select, text, options (MC), correctAnswer, points.
|   |           MC: dynamic option list with Add/Remove Option buttons.
|   |
|   +-- EditExamPage                    (client/src/pages/teacher/EditExamPage.jsx)
|   |   |   Same form as Create, pre-filled via examService.getExamById(id).
|   |   |   Banner shown for Published/Closed exams.
|   |   |   Status field stripped by examService.updateExam() (cannot bypass machine).
|   |   |
|   |   +-- QuestionEditor (local)      Same shape as in CreateExamPage.
|   |           Existing questions hydrated via toEditorQuestion() helper.
|   |
|   +-- SubmissionsPage                 (client/src/pages/teacher/SubmissionsPage.jsx)
|           Grouped by exam. Two concurrent calls:
|             examService.getExamsByTeacher + mockApi.get('submissions').
|           Filters and groups in JS. Sorted by submission count (exams with
|           more submissions appear first).
|           Read-only in M1; grading UI is Milestone 2.
|
+-- Student Pages  (all behind ProtectedRoute role="student")
|   |
|   +-- StudentDashboard                (client/src/pages/student/StudentDashboard.jsx)
|   |       Counter cards: Available, Submitted, Graded.
|   |       Two concurrent calls: getPublishedExams + getSubmissionsByStudent.
|   |       Derives counts in JS using a Set of submitted exam IDs.
|   |       Quick-links: View Available Exams, View My Grades.
|   |
|   +-- AvailableExamsPage              (client/src/pages/student/AvailableExamsPage.jsx)
|   |       CRITICAL: uses getPublishedExams() only -- never shows Draft or Closed.
|   |       Two concurrent calls: getPublishedExams + getSubmissionsByStudent.
|   |       Hides exams the student has already submitted.
|   |       Table: title, description preview, duration, question count, Start button.
|   |       Start button links to /student/exams/:id.
|   |
|   +-- TakeExamPage                    (client/src/pages/student/TakeExamPage.jsx)
|   |       Guards on load:
|   |         (1) Exam must exist.
|   |         (2) Exam must be Published (rejects Draft and Closed).
|   |         (3) Student must not have already submitted (redirect /student/grades).
|   |       Question rendering:
|   |         multiple-choice -> <input type="radio"> per option inside <fieldset>
|   |         open-text       -> <textarea>
|   |       Draft auto-save: answers written to StorageService on every change,
|   |         key ems_draft_<examId>_<studentId>. Cleared on submit.
|   |       Unanswered-question warning shown inline; submission not blocked.
|   |       On submit: submissionService.submitExam -> clear draft -> /student/grades.
|   |
|   +-- GradesPage                      (client/src/pages/student/GradesPage.jsx)
|           Two concurrent calls: getSubmissionsByStudent + getAllExams.
|           Joins by examId in JS to resolve exam title (no N+1).
|           Table: Exam, Submitted, Status badge, Grade, Feedback.
|           Sorted most-recent-first.
|
+-- Misc
    |
    +-- NotFoundPage                    (client/src/pages/NotFoundPage.jsx)
            Rendered for path="*" (any unmatched URL).


NOTES ON DIVERGENCE FROM §15.1 TEMPLATE
-----------------------------------------
1. The template shows "PageContainer (<Outlet />)" as a named child of
   MainLayout. In the actual code this is the unnamed <main> element
   inside MainLayout that wraps <Outlet />. There is no PageContainer
   component or file.

2. LandingRedirect is not a separate file or exported component. It is an
   inline function component defined inside routes.jsx and used as the
   element for the "/" route.

3. ProtectedRoute is not listed in the template hierarchy but is a real
   shared component (components/shared/ProtectedRoute.jsx) that wraps every
   teacher and student page route.

4. QuestionEditor is not a standalone file. It is a local unexported
   sub-component defined inside CreateExamPage.jsx and duplicated inside
   EditExamPage.jsx (intentional M1 simplicity; extraction deferred to M2).

5. NotFoundPage is an additional page not shown in the §15.1 template.
