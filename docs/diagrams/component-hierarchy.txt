SHARED
======
ProtectedRoute            components/shared/ProtectedRoute.jsx
  Redirects an unauthenticated visitor to /login, and a user with the
  wrong role to their own dashboard.
  A convenience, NOT a security boundary — the server refuses the
  request regardless.

SERVICES (not components; injected via services/index.js)
=========================================================
config, logger, storage, notify
api                HttpApiService — the only client code that leaves    [M2]
                   the browser. Holds the JWT.
auth               login, register, role checks (synchronous reads)
examService        exam CRUD, publish, close
submissionService  attempts, autosave, submission, grading
aiService          generation, AI grading                               [M2]
analyticsService   statistics                                           [M2]

Pages never call fetch. Models never import services.
