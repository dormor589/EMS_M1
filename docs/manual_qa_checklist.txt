Step 9 — Open exam and submit answers
------------------------------------------------------------
Result : PASS
Evidence:
  - "Start Exam" → /student/exams/:id → TakeExamPage
    (client/src/pages/student/TakeExamPage.jsx).
  - Entry guards (useCallback on [examId, navigate]):
      Guard 1: exam not found → setError.
      Guard 2: exam.status !== 'Published' → setError.
      Guard 3: existing submission → navigate('/student/grades', {replace:true}).
  - Draft answer auto-save: handleAnswer(questionId, value) →
      storage.set(ems_draft_<examId>_<studentId>, { [questionId]: value })
      (StorageService is the ONLY file touching localStorage — constraint met).
  - On page load: draft rehydrated from storage.get(draftKey).
  - MC questions render as <fieldset> with <input type="radio"> per option.
  - open-text questions render as <textarea>.
  - Unanswered questions shown in warning banner on submit, but do NOT block.
  - Submit: submissionService.submitExam({examId, studentId, answers}):
      Guard A: exam must be Published.
      Guard B: getSubmissionByExamAndStudent(examId, studentId) must be null
               (throws Error('Already submitted') on duplicate).
      Persists: { id: UUID, examId, studentId, answers, status:'submitted',
                  grade:null, feedback:'', submittedAt: ISO } via mockApi.post.
  - storage.remove(draftKey) — draft cleared on success.
  - navigate('/student/grades').

      state after reload.
