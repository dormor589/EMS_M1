## D012 — Generate PNG renders from PlantUML diagrams

**Date:** 2026-05-24
**Status:** active
**Tier:** 1 (no logic, no LOC; build output only)
**Risk class:** LOW
**Depends on:** D008 (PlantUML sources exist)
**Estimated time:** ~10 min
**QA dispatch:** **NO** — Tier 1; Team Lead reviews the resulting files directly.

### Goal

Render the two PlantUML sources to PNG so they're viewable on GitHub without a renderer.

### Inputs

- `client/../docs/diagrams/class-diagram.puml`
- `client/../docs/diagrams/use-case-diagram.puml`

(Full paths: `deployments/EMS_M1/docs/diagrams/*.puml`.)

### What to do

1. **Install `plantuml` if not present:**
   ```bash
   command -v plantuml >/dev/null || brew install plantuml
   ```
   `plantuml` requires Java; brew pulls it as a dependency. If `brew install` fails (no Homebrew, no network), STOP and write `audits/D012_implementer_progress.md` with the specific blocker — do NOT try to install from source or pip; that's out of scope.

2. **Render both PNGs:**
   ```bash
   cd /Users/dormor/Desktop/Stocks/QuantDeploy/deployments/EMS_M1/docs/diagrams
   plantuml class-diagram.puml use-case-diagram.puml
   ```
   This generates `class-diagram.png` and `use-case-diagram.png` in the same folder.

3. **Sanity-check:**
   - Both PNGs exist and are non-zero bytes.
   - `file class-diagram.png` reports `PNG image data`.
   - `file use-case-diagram.png` reports `PNG image data`.

4. **Update README.md** (top-level deployment README, not client/README) to add a short "Diagrams" section linking to the PNGs:
   ```
   ## Diagrams

   Source files live in `docs/diagrams/` (`.puml` for PlantUML, `.txt` for plain text).
   Pre-rendered PNGs for the PlantUML diagrams:

   - ![Class diagram](docs/diagrams/class-diagram.png)
   - ![Use case diagram](docs/diagrams/use-case-diagram.png)
   ```

### Required commit structure

Two commits, separate:

1. `docs: add pre-rendered PNGs for PlantUML diagrams`
2. `docs: link diagram PNGs from README`

After: `git push origin dev`.

### Acceptance criteria

- [ ] `docs/diagrams/class-diagram.png` exists, non-zero, `PNG image data`.
- [ ] `docs/diagrams/use-case-diagram.png` exists, non-zero, `PNG image data`.
- [ ] README has "Diagrams" section with both image embeds.
- [ ] On GitHub https://github.com/dormor589/EMS_M1/tree/dev/docs/diagrams the PNGs render.
- [ ] 2 conventional commits pushed.

### Out of scope

- Re-rendering the .puml sources differently / restyling.
- Adding more diagrams.
- Generating SVG (PNG is enough).
- Setting up CI to auto-render.

### Failure modes

- **`brew install plantuml` fails (no network or Homebrew not installed):** STOP, write `audits/D012_implementer_progress.md` describing the blocker, exit. Team Lead will resolve (probably with online rendering and a manual asset commit).
- **PlantUML produces a warning but writes a valid PNG:** warning is fine — proceed.
- **PNG is 0 bytes or `file` reports something other than PNG:** treat as failure, write progress + exit.

### Deliverable

- 2 PNGs in `docs/diagrams/`.
- README updated.
- Implementer report: `audits/D012_implementer_report.md`.
