### What to build

#### 1. SubmissionService (`client/src/services/SubmissionService.js`)

Per spec §8:

```js
class SubmissionService {
  constructor(mockApi, examService, config, logger) { ... }
  async submitExam({ examId, studentId, answers })  // creates Submission
  async getSubmissionsByExam(examId)
  async getSubmissionsByStudent(studentId)
  async getSubmissionByExamAndStudent(examId, studentId)  // one or null
  async gradeSubmission(id, { grade, feedback })          // M2 placeholder OK in M1
}
```

- `submitExam`: only allowed if the exam exists and is Published; reject otherwise. Assign `id = crypto.randomUUID()`, `status = "submitted"`, `submittedAt = ISO timestamp`, `grade = null`, `feedback = null`. Persist via MockApi.
- One submission per (examId, studentId) — calling `submitExam` twice for same pair throws `Error('Already submitted')`.
- `gradeSubmission` updates grade + feedback; OK to leave as plain field-update in M1 (no teacher UI for grading yet — only a stub).

#### 2. Student pages

**StudentDashboard.jsx**
- Counters: available (Published not yet submitted), submitted, graded.
- Links: "View available exams", "View my grades".

**AvailableExamsPage.jsx**
- Lists Published exams that the current student has NOT yet submitted.
- Each row: title, description preview, duration, # questions, "Start exam" button → `/student/exams/:id`.
- If a student already submitted, that exam is hidden (or shown disabled — pick one and document).

**TakeExamPage.jsx**
- Loads exam by `:id`; sanity-check it's Published, student hasn't already submitted.
- Renders each question: MC as radio buttons, open-text as textarea.
- "Submit answers" button at bottom → SubmissionService.submitExam → notify success → navigate to `/student/grades`.
- Basic validation: warn if no answer for a question, but allow submission (M2 will enforce more strictly).
- Optional Nice-to-Have (brief §5.2): auto-save draft answers in localStorage via StorageService keyed by `ems_draft_${examId}_${studentId}`. Implement IF it fits cleanly; skip if costs a full sub-day.

**GradesPage.jsx**
- Lists student's submissions: exam title, submitted date, grade (or "not yet graded"), feedback (or "—").

#### 3. SubmissionsPage (teacher side — re-wire)

Replace D006 stub. Lists teacher's own exams; each row "View N submissions" expandable or links to a sub-view showing submitter, submitted-at, current grade. Grading UI is M2 — just display in M1.
