## D001 — Project scaffold + dev branch + JS/TS decision

**Date:** 2026-05-23
**Status:** active
**Tier:** 3
**Risk class:** HIGH
**Depends on:** nothing
**Estimated time:** ~1h

### Spec source

`docs/spec_brief.txt` §6 (Recommended Architecture) and §10 (Git Workflow).

### Affected zones

- New: `client/**`, `server/**`, top-level `README.md`.
- Git: branch model.

### Test surface

- `cd client && npm run build` succeeds (or `npm run dev` boots without errors).
- `cd server && node src/app.js` boots; `curl localhost:<port>/health` returns 200.
- No Vitest tests required yet (services begin in D002).

### Expected wall time

~30–60 min (mostly `npm install`).

### What to build

1. **Decide JS vs TS** at the top of your work. Default is **JavaScript** unless you can cite a strong project-fit reason for TypeScript. Record the decision and rationale in `docs/ai-work-log.txt` under a "D001 — Stack decision" entry. Once chosen, the whole deployment commits to that choice — no mid-flight switch.

2. **Vite + React client scaffold** at `client/`:
   - Use `npm create vite@latest client -- --template react` (or `react-ts` if TS chosen). Confirm React 18+.
   - Set up the folder layout per spec §6:
     ```
     client/src/
       app/           (App.jsx, routes.jsx — empty placeholders ok)
       components/
         layout/      (NavigationMenu.jsx placeholder, MainLayout.jsx placeholder)
         shared/
       pages/
         auth/        (LoginPage.jsx, RegisterPage.jsx — placeholders)
         teacher/     (5 page placeholders per spec §6)
         student/     (4 page placeholders per spec §6)
       services/      (empty — D002+)
       data/          (empty — D003)
       models/        (empty — D003)
       styles/        (empty)
     ```
   - Placeholder pages: each exports a default React component rendering an `<h1>` with the page name. No logic. This proves routing is plumbable in D005.
   - Update `client/src/App.jsx` to render a simple "EMS_M1 — Milestone 1 scaffold ready" landing message. Vite default page is removed.
   - Add `react-router-dom` to dependencies (D005 will use it).

3. **Express server skeleton** at `server/`:
   - `npm init -y`, install `express` + `cors`.
   - Folder layout per spec §6:
     ```
     server/src/
       app.js
       routes/
       controllers/
       services/
       models/
       middleware/
     ```
   - `app.js` boots Express on port 4000 (configurable via `PORT` env), CORS enabled, with:
     - `GET /health` → `{ status: "ok", milestone: "M1", time: <ISO> }`
   - No real routes, no auth, no DB. Skeleton ONLY.

4. **Top-level `README.md`** describing:
   - Project name + milestone.
   - How to install and run the client (`cd client && npm install && npm run dev`).
   - How to run the server (`cd server && npm install && node src/app.js`).
   - Link to `docs/explanation.txt` and `docs/spec_brief.txt`.
   - Note: GitHub repo at https://github.com/dormor589/EMS_M1, working branch `dev`.

5. **Git: switch to `dev` branch**:
   - From the inner repo root (`deployments/EMS_M1`):
     ```
     git checkout -b dev
     ```
   - All D001 commits land on `dev`. Do not touch `main` further this milestone.
   - Push `dev` to origin: `git push -u origin dev`.

6. **`docs/ai-work-log.txt`** — create it (plain text) and add the first entry:
   ```
   D001 — <timestamp>
     Stack decision: <JS|TS>, rationale: <one sentence>.
     Files added: <count>.
     Wall time: <minutes>.
   ```

### Out of scope (do NOT implement now)

- Any service classes (D002, D003).
- Real auth, real DB, JWT, bcrypt (M2+).
- Page content beyond placeholder `<h1>` per page.
- Routing / route guards (D005).
- Diagrams, explanation.txt (D008).

### Failure modes to handle

- **`npm create vite` fails / network issue** — retry once; if persistent, write `audits/D001_implementer_progress.md` describing the blocker and exit with `clarification_request`.
- **Port 4000 already in use** — pick 4001 and document in README.
- **No global `npm`** — escalate via `clarification_request`.
