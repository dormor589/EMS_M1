### What to build

#### 1. Submission detail view

`SubmissionDetailPage.jsx` rendered at `/teacher/submissions/:id` (wrapped in `<ProtectedRoute role="teacher">`).

On mount:
- Read `id` from `useParams()`.
- Fetch the submission via SubmissionService (add `getSubmissionById(id)` to the service if not present — it's a thin wrapper around `mockApi.getById('submissions', id)`).
- Fetch the related exam via ExamService.getExamById(submission.examId).
- Fetch the submitting student via a small helper: either `authService.getUserById(id)` (add a thin method if missing — wraps `mockApi.getById('users', id)`) or expose via existing MockApi.

Render:

```
Header:
  Exam title:           <exam.title>
  Student name:         <user.name>
  Submitted at:         <ISO timestamp, human-readable>
  Current grade:        <submission.grade ?? "Not yet graded">

For each question in exam.questions:
  Question N:           <question.text>
  Type:                 <question.type>
  Student answer:       <submission.answers.find(a => a.questionId === q.id)?.value ?? "(no answer)">
```

Display is read-only for questions + answers. No per-question grading in M1.

#### 2. Grading form (at bottom of the detail page)

```jsx
<form onSubmit={handleSaveGrade}>
  <label>Grade (0–100):
    <input type="number" min="0" max="100" required value={grade} onChange={...} />
  </label>
  <label>Feedback (optional):
    <textarea value={feedback} onChange={...} />
  </label>
  <button type="submit">Save grade</button>
</form>
```

On submit:
- Validate: grade is a number in `[0,100]` (the `<input type=number min max>` enforces; also validate in JS for safety).
- Call `submissionService.gradeSubmission(submission.id, { grade: Number(grade), feedback })`.
- On success: NotifyService.success("Grade saved"); re-fetch the submission so the "Current grade" header updates.
- On error: NotifyService.error(err.message).

If the submission already has a grade, pre-fill the form with the existing values so the teacher can edit, not just re-grade from zero.

#### 3. SubmissionsPage list — add click-through

Update existing `SubmissionsPage.jsx` so each row's submitter / timestamp links to `/teacher/submissions/:id`. Use `<Link to={...}>` from `react-router-dom`. Keep the rest of the page (per-exam grouping, etc.) intact.

Also: add a "Grade" column showing the current grade (or `—` if ungraded), so the teacher sees at-a-glance which submissions still need grading.

#### 4. Student GradesPage — sanity-check

GradesPage was already built in D007 and should display `grade` + `feedback` if set. Verify it renders correctly with non-null values. If anything was assuming `grade === null` for "not yet graded" and breaks on a real number, fix that.

#### 5. NavigationMenu — verify "Submissions" link still works

The teacher nav already has "Submissions" → `/teacher/submissions`. No change needed unless the URL pattern shifted.

### Acceptance criteria

- [ ] Teacher can click a submission row → lands on `/teacher/submissions/:id` with student name, exam title, timestamp, all questions + answers visible.
- [ ] Grade form accepts 0–100 numeric input + optional feedback; "Save grade" persists via existing service.
- [ ] After saving, the detail page shows the new grade.
- [ ] Student logs in, navigates to GradesPage → sees the grade and feedback for that exam.
- [ ] Editing a previously-graded submission pre-fills the form and updates on save.
- [ ] Cumulative `npx vitest run` passes 100%.
- [ ] `npm run build` succeeds with no new warnings.
- [ ] ≥4 conventional commits on `dev`; pushed.

### Out of scope (DO NOT BUILD)

- Per-question grading (one grade per question instead of one per submission).
- Automatic / AI grading.
- Feedback rich-text editor.
- Bulk grading / batch actions.
- Publish-results workflow (separate UI to "release" grades).
- Notifications to student when graded.
- Exam status transition triggered by grading.

### Failure modes

- Submission not found (bad URL) → render a "Submission not found" message + link back to `/teacher/submissions`; don't crash.
- Exam deleted but submission exists → graceful "Exam no longer available" message.
- Grade out of range → form validation rejects before service call.
